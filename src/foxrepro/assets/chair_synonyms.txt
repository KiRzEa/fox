# CHAIR synonym list for the 80 MS-COCO object categories.
#
# provenance: transcription-of-rohrbach-synonyms-txt
# upstream: https://github.com/LisaAnne/Hallucination  ->  data/synonyms.txt
#   (Rohrbach et al., "Object Hallucination in Image Captioning", EMNLP 2018)
#
# FORMAT: one line per COCO category. Fields are comma-separated. The FIRST
# field is the canonical COCO category name (the "node word"); every other
# field is a surface synonym that maps onto it. Lines starting with '#' and
# blank lines are ignored. Duplicate surface forms within a line are allowed
# and ignored; the same surface form must not appear in two different lines.
#
# WARNING -- READ BEFORE QUOTING ANY CHAIR NUMBER
# CHAIR is highly sensitive to this list: adding or dropping synonyms moves
# CHAIR_I by whole points, and published CHAIR numbers are only comparable
# when they use the identical list. This file is a transcription of the
# upstream list, not a byte-identical copy of it. `bench/chair.py` records the
# SHA-256 of whatever file it actually loaded in every metrics output, and
# `bench/report.py` prints it, so a swap is always visible after the fact.
# If you obtain the upstream `synonyms.txt`, drop it in as
# `data/chair_synonyms_upstream.txt` and pass `--synonyms` to evaluate.py;
# the recorded checksum will then differ from the one in this file, which is
# exactly the signal you want.
